\chapter{Discussion et prise de decision}

\section{Pourquoi je retiens l'occlusion}
Mon choix final \texttt{baseline + occlusion} repose sur trois elements:
\begin{itemize}
  \item \textbf{coherence avec le traitement de point clouds}: les points manquants en zone localisee sont un cas realiste en acquisition 3D;
  \item \textbf{stabilite entre campagnes}: l'occlusion reste bien classee en C1 et arrive premiere en C2;
  \item \textbf{impact final sur test}: les runs archives montrent une progression nette (90.09\% puis 90.75\%), et le run seed 50 est ajoute pour confirmer cette tendance.
\end{itemize}

\section{Ce que j'ai appris des autres essais}
\begin{itemize}
  \item \texttt{jitter} peut etre excellent ponctuellement, mais moins stable selon les protocoles;
  \item les combinaisons lourdes ne donnent pas automatiquement un gain;
  \item \texttt{dropout}, \texttt{scale} et \texttt{translate} sont utiles pour diversifier, mais n'ont pas suffi seuls pour battre durablement l'occlusion.
\end{itemize}

\section{Lien avec l'evaluation pedagogique}
Comme le professeur l'a precise, la note ne depend pas uniquement du score maximal.
J'ai donc essaye de montrer une logique complete: hypothese, protocole, comparaison, puis justification argumentee du choix final.

\section{Limites de ma version actuelle}
\begin{itemize}
  \item je dois encore consolider un vrai tableau \emph{mean\(\pm\)std} sur plusieurs seeds pour toutes les configs;
  \item je n'ai pas encore archive quantitativement de facon homogène toute la transition PointMLP \(\rightarrow\) PointNetBasic \(\rightarrow\) PointNetFull sur une meme grille d'epochs;
  \item je reste focalise sur ModelNet10, alors qu'une extension ModelNet40 serait interessante pour generaliser la conclusion.
\end{itemize}
