\chapter{Conclusion}

Dans ce travail, j'ai essaye de montrer a la fois les resultats et la logique qui m'y conduit.
J'ai implemente les trois etapes demandees (PointMLP, PointNetBasic, PointNetFull), puis j'ai construit une comparaison experimentale pour choisir une politique d'augmentation defendable.

La conclusion que je retiens est la suivante: pour mon contexte de point clouds ModelNet10, l'occlusion est l'augmentation la plus pertinente pour un bon compromis robustesse / performance.

La suite immediate est claire:

\end{itemize}
