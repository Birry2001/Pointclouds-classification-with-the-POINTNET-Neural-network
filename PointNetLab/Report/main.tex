\chapter*{Résumé}
\addcontentsline{toc}{chapter}{Résumé}
Ce rapport présente l'implémentation en PyTorch de trois modèles de classification 3D sur ModelNet10~: un MLP de base, PointNet basique, puis PointNet avec T-Net et régularisation.
Le protocole final applique un découpage train/validation/test propre, un early stopping piloté sur validation, et une augmentation finale focalisée sur l'occlusion.
Le meilleur run final atteint environ \textbf{90\%} d'accuracy test avec la configuration \emph{baseline + occlusion}.
